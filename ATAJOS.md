# ⌨️ Atajos de IntelliJ IDEA para Kotlin

| Acción | Atajo |
|---|---|
| Autocompletar código | `Ctrl + Space` |
| Soluciones rápidas / sugerencias | `Alt + Enter` |
| Ejecutar el programa | `Shift + F10` |
| Compilar el proyecto | `Ctrl + F9` |
| Deshacer | `Ctrl + Z` |
| Rehacer | `Ctrl + Shift + Z` |
| Copiar | `Ctrl + C` |
| Cortar | `Ctrl + X` |
| Pegar | `Ctrl + V` |
| Buscar en el archivo | `Ctrl + F` |
| Buscar y reemplazar | `Ctrl + R` |
| Duplicar línea | `Ctrl + D` |
| Eliminar línea | `Ctrl + Y` |
| Mover línea hacia arriba | `Ctrl + Shift + ↑` |
| Mover línea hacia abajo | `Ctrl + Shift + ↓` |
| Ir a la definición | `Ctrl + B` |
| Ver parámetros de una función | `Ctrl + P` |
| Buscar cualquier cosa | `Shift + Shift` |
| Seleccionar progresivamente código | `Ctrl + W` |
